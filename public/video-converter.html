Video Format Converter Guide

This guide will help you convert your videos to formats that are widely supported by web browsers. If your videos aren't playing correctly, converting them to a more compatible format can often solve the issue.

Option 1: Using FFmpeg (Recommended)

Step 1: Install FFmpeg

FFmpeg is a powerful command-line tool for video conversion.

  • Windows: Download from ffmpeg.org or install with winget install ffmpeg
  • macOS: Install with Homebrew: brew install ffmpeg
  • Linux: Use your package manager, e.g., sudo apt install ffmpeg

Step 2: Convert to MP4 (H.264)

This format has the best browser compatibility:

ffmpeg -i input.mp4 -c:v libx264 -profile:v baseline -level 3.0 -pix_fmt yuv420p -c:a aac -movflags +faststart output.mp4

Step 3: Create WebM version (optional but recommended)

WebM is well-supported in Chrome and Firefox:

ffmpeg -i input.mp4 -c:v libvpx-vp9 -b:v 1M -c:a libopus output.webm

Option 2: Using Online Converters

If you don't want to install software, you can use these online services:

  • CloudConvert
  • Online-Convert
  • Convertio

When converting, use these settings:

  • Format: MP4
  • Video Codec: H.264
  • Audio Codec: AAC
  • Resolution: Same as original or lower (720p is usually sufficient)
  • Bitrate: 1-2 Mbps for standard quality

Option 3: Recommended Video Settings

If you're creating videos from scratch, use these settings for maximum compatibility:

  • Container: MP4
  • Video Codec: H.264 (AVC)
  • Audio Codec: AAC
  • Profile: Baseline or Main
  • Resolution: 1280x720 (720p) or 1920x1080 (1080p)
  • Frame Rate: 30fps
  • Pixel Format: YUV420P
  • Bitrate: 2-5 Mbps depending on quality needs

Testing Your Converted Videos

After converting your videos:

  1. Upload them to your Vercel Blob Storage
  2. Test them using the Direct Video Test page
  3. If they work there but not in your app, the issue is with your application code
